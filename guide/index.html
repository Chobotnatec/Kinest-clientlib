Kinest Application Tutorial

Tracking Robots and Objects with Precision

A. Camera Calibration

Before starting tracking, each camera must be calibrated. Calibration ensures accurate pose estimation and robust tracking.

1. Prepare the Calibration Pattern

You will need a high-precision calibration pattern. You can:

  • Order printed patterns from kinest.cz/patterns (recommended to support development).
  • Print available patterns using a high-quality printer.
  • Display the pattern on a high-resolution PC screen.

2. Select Camera and Format

In the camera selection menu, choose your desired camera, resolution, and pixel format.

  • Recommended formats: YUV, GREY, or RGB
  • Not recommended: JPEG (due to decoding latency)

3. Load Calibration Metadata

Point the camera at the QR code on the calibration board. The application will automatically load and display the metadata.

4. Capture Calibration Shots

Position the camera in recommended poses and press the "Capture" button. The button will turn green. The app captures the image automatically once the camera is steady.

An audio cue and button reset confirm the capture.

Try to fill the corners of the image with the calibration board. Closer shots are better than distant ones.

A typical calibration involves 6 shots:

  • 2 from the front
  • 2 from the sides
  • 2 from angled positions

5. Review and Save Calibration

Use the "Review Photos" menu to inspect captured images. If satisfied, press the "Save" button to store the calibration.

Calibration must be performed for each unique combination of camera, resolution, and pixel format.

B. Marker Tracking

Once calibration is complete, you can begin real-time tracking.

1. Select Camera and Resolution

Go to the "Camera" menu and select a previously calibrated camera and resolution. The video stream should now be visible.

2. Select Marker Dictionary and Size

In the "Tracking" menu:

  • Select the dictionary from which your markers are generated.
  • Choose the physical size of the markers.

Markers should be printed on rigid, flat surfaces. For optimal results, we recommend ordering them from our store.

3. Choose Reference Frame

Define the reference frame for coordinate estimation:

  • Camera: Positions are relative to the camera.
  • Static OXY: Origin (ID 8), X direction (ID 9), Y marker (ID 10). Used when markers are stationary.
  • Dynamic OXY: Same as above, but allows movement of camera and reference markers.
  • Single Marker: Reference frame defined by one marker (less precise).

4. Set Data Output

Set the IP address and port for UDP data streaming. The default port is 63232, but this can be changed as needed.

Ensure that the receiving system is ready to handle incoming UDP packets on the specified port.

Summary

Kinest offers an accurate and efficient way to calibrate and track objects using visual markers. Designed for use in robotics clubs and industrial settings, its flexibility and precision make it ideal for a wide range of applications.

By following the calibration and tracking steps outlined above, users can expect reliable performance in real-time robotic environments.
